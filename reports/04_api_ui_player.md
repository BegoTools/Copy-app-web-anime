# تقرير الواجهة والسيرفر الداخلي ومشغل الفيديو (API, UI & Player Architecture Report)

**تاريخ المراجعة:** 24 أكتوبر 2026  
**الهدف:** توحيد عناوين الشبكة، توثيق مسارات السيرفر المحلي ومسارات واجهة الويب، وتحديد وضع مشغل الفيديو `ffplay.elf`.

---

## 1. حل تضارب عناوين الشبكة (Network IP Alignment)

### المشكلة السابقة:
- ملف `assets/pc_server.txt` كان يحمل العنوان الثابت: `http://192.168.1.66:8080/`.
- كود C++ في `main.cpp` كان يستخدم fallback مختلف: `http://192.168.1.100:8080`.
- السيرفر المدمج داخل PS5 يستمع فعلياً على المنفذ: `8090` (`127.0.0.1:8090`).
- كود `homebrew.js` كان يبحث عن: `window.location.hostname:8080`.

### الحل المطبق:
1. تم توحيد العنوان الافتراضي في `assets/pc_server.txt` وكود `main.cpp` ليكون:
   `http://127.0.0.1:8090/`
2. بهذه الطريقة يعمل التطبيق كـ **Standalone PS5 Player** بدون الحاجة لكمبيوتر خارجي، حيث يتصل مباشرة بالسيرفر المدمج في `eboot.bin`.
3. إذا أراد المستخدم الاتصال بسيرفر الكمبيوتر المنزلي (LAN Proxy Gateway)، يمكنه ببساطة تعديل السطر في ملف `assets/pc_server.txt` إلى عنوان الآي بي الخاص بجهازه (مثلاً `http://192.168.1.150:8080/`) دون الحاجة لإعادة ترجمة التطبيق.

---

## 2. هيكلية السيرفر المحلي والمسارات المدعومة (Embedded HTTP Server Routes)

يقوم السيرفر المحلي العامل على منفذ `8090` في خلفية التطبيق بخدمة المسارات التالية:

| المسار (Route) | نوع الطلب (Method) | المصدر والوظيفة |
|---|---|---|
| `/` و `/index.html` | `GET` | تقديم واجهة التلفاز الرئيسية (10-Foot UI) |
| `/styles.css` | `GET` | ملفات التنسيق ودعم الوضع الداكن والخطوط |
| `/app.js` | `GET` | منطق التطبيق التفاعلي ودعم يد التحكم |
| `/hls.min.js` | `GET` | مكتبة تشغيل بث الفيديو المباشر HLS |
| `/api/home` | `GET` | جلب الواجهة الرئيسية (مع دعم Fallback من `api_cache/home.json`) |
| `/api/schedule` | `GET` | جدول مواعيد الأنمي (مع Fallback من `api_cache/schedule.json`) |
| `/api/userdata` | `GET / POST` | حفظ واسترجاع المفضلة وسجل المشاهدة واللغة |
| `/assets/*` | `GET` | خدمة الصور والأيقونات والأعلام والرسوم المتحركة |

## 3. وضع مشغل الفيديو `ffplay.elf`

1. **طبيعة الملف الحالي:**
   - الحجم: 41,849,656 بايت.
   - ترويسة الملف: `ELF64 x86-64 / System V / DYN` (معرّف نوع ELF هو 3، و OS/ABI هو 0).
   - **النتيجة الفنية:** هذا الملف تم بناؤه بنظام تشغيل Linux/SysV وليس منسقاً كـ Native PS5 Executable (`0xFE10` مع FreeBSD ABI 9).
2. **عزل المشغل لمنع تعليق التطبيق:**
   - تم عزل `ffplay.elf` تماماً عن مسار إقلاع التطبيق الأصلي (`eboot.bin`).
   - إقلاع التطبيق وعرض الشاشة الرئيسية والواجهة لا يعتمدان إطلاقاً على `ffplay.elf`.
   - في واجهة الويب يتم استخدام مشغل HLS الداخلي عبر المتصفح (`hls.min.js`) كمسار افتراضي ومستقر.
