# 🎮 Anime Rift — PlayStation 5 Edition (FW 13.60 Jailbreak)

نسخة كاملة ومفتوحة المصدر من تطبيق **Anime Rift (v3.13.5)** تم عمل الهندسة العكسية لها بالكامل من ملف `app.apk` (`libapp.so` Dart 3.10.7 AOT) باستخدام **REA** لتعمل خصيصاً على جهاز **PlayStation 5 (إصدار 13.60 المهكر بـ Relapse / kstuff-lite / WebSrv)** مع دعم كامل لذراع **DualSense** وبدون أي إعلانات أو تسجيل دخول أو قيود اشتراك.

## 🚀 طريقة التشغيل على البلايستيشن 5 (إصدار 13.60)

1. **تشغيل سيرفر البروكسي المحلي**:
   - اضغط مرتين على `start_ps5_server.bat` (أو شغل `python server.py`).
   - سيظهر لك عنوان الـ IP الخاص بجهازك على الشبكة المحلية (مثلاً: `http://192.168.1.X:8080`).
2. **التشغيل من البلايستيشن 5**:
   - **الطريقة الأولى (عبر حزمة `.pkg` / `ps5-payload-websrv`)**:
     - ثبت ملف `ps5_package/ANIME_RIFT_PS5_1360.pkg` عن طريق `Debug Settings > Package Installer` بعد تفعيل `kstuff-lite`، أو انسخ مجلد `ps5_package/websrv_app` إلى مسار `websrv` على جهازك.
   - **الطريقة الثانية (مباشرة من متصفح PS5 أو DNS Redirect)**:
     - افتح العنوان الظاهر في نافذة `start_ps5_server.bat` (`http://<IP>:8080`) مباشرة على جهاز PS5.

## 🛠️ كيف تعدل على النسخة الخاصة بك في أي وقت؟

1. عدّل أي شيء تريده في:
   - `web/index.html` أو `web/styles.css` (لتغيير الشكل والألوان).
   - `web/app.js` (لتغيير سلوك المشغل أو الأزرار أو الأقسام).
   - `server.py` (لتعديل أو إضافة مسارات API).
2. بعد التعديل، شغّل الأمر التالي لإعادة بناء ملف `.pkg` فوراً:
   ```powershell
   python build_ps5_pkg.py
   ```
